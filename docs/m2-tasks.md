# Carelogue — M2 任务卡（附件 + 测量图表）

> 用法同 M1：一张一张来；每张卡交给 Claude Code，对照"验收"手工过一遍再开下一张。
> Spec 依据：mvp-spec.md 第 3/4/10 节（P3 附件区、Artifact、M2 里程碑）。
> 现有基础（M1 已完成）：Artifact 模型（externalStorage）、时间线测量折叠卡（含展开）、Theme.swift 颜色集中管理。附件 UI、图表、深色模式为空白。
> 总预估：~15h。

---

## T10 · 附件导入（~3h）
- **做**：就诊 Log 编辑器加"附件区"：PhotosPicker 相册多选（图片）+ `.fileImporter`（PDF/图片文件）；图片压缩后存入 Artifact（`fileData` + `fileName` + `mime`；JPEG 质量 ~0.8、长边 ≤2048px，避免原图直存）；保存即落盘
- **验收**：新建就诊 Log 加 2 张照片 + 1 份 PDF；杀 app 重开，附件都在
- **学习点**：PhotosPicker、fileImporter、Data 与 externalStorage

## T11 · 附件展示 / 预览 / 删除（~3h）
- **做**：Log 详情页附件区：图片缩略图网格 + PDF 文件行（图标 + 文件名）；点击全屏预览——图片可缩放，PDF 用 QuickLook（PDFKit）包装；删除（带确认），删除同时清理文件
- **验收**：图片/PDF 都能打开看；删除后重开不复活；数据无残渣
- **学习点**：fullScreenCover、QuickLook/PDFKit、级联删除

## T12 · 测量列表增强（~2h）
- **做**：展开的测量列表加"类型筛选 chips"（体重/血压/…，仅当 ≥2 种类型时显示）；列表行点击进编辑（≤3 击）；沿用现有 MeasurementRow 样式
- **验收**：多类型混排下筛选正确；任意行 ≤3 击到编辑/删除
- **学习点**：动态筛选、列表分段

## T13 · 测量图表（~3h）
- **做**：Swift Charts 折线图：选类型（如体重）→ 按时间绘制数值；入口放测量展开区（"查看图表" → sheet）；处理 0/1 个点的空态
- **验收**：20 条体重数据曲线可读（日期轴合理）；1 个点不崩；新增数据后图表更新
- **学习点**：Charts 框架、图表状态
- **已知限制**：血压暂按单值（收缩压）记录，舒张值可写备注——双值字段留 M4/v1.1

## T14 · 深色模式（~2h）
- **做**：Theme.swift 的 6 个颜色改为动态色（跟随系统，`UIColor { traits }` 分支写法，单一来源保持此文件）；深色 v0：accent `#E08A63` · 背景 `#17140F` · 卡片 `#221E1A` · 主墨 `#F5F1EC` · 次墨 `#A39C93` · 边框 `#332E28`（以 Stitch 深色稿校准后的定稿为准，见 docs/design/stitch/dark-mode-prompt.md）；通查视图无硬编码色残留
- **验收**：系统切深色后 P1–P3 全正常（无白底残留、对比度可读）；跟随系统切换即可，**不做**手动开关（v1.1 再议）
- **学习点**：ColorScheme、动态颜色

## T15 · M2 验收走查（~2h）
- **做**：手工过：附件全流程（导入 → 预览 → 删除 → 重开后一致）+ 图表；对照 spec A1 场景（含附件的完整记录）；把卡壳点记成 issues
- **验收**：照片/PDF 各 2 份流程不离开 app；产 M3 开工的 bug 清单
- **产出**：M2 bug 清单
