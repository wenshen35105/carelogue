## 设置与周边页（MVP 口径）

- **原则**：每一项设置必须对应一个已存在的功能；没有功能 = 没有设置项。
- **MVP 设置最小集（3 项）**：
  1. AI 总开关（全局 + 旅程级）—— M3 启用
  2. 隐私说明（"数据只存本机；AI 按动作触发、不存储"）—— M3 启用
  3. 清空数据 —— M1 起放在 Profile 页底部即可，无需独立页
- **导航修正（对 Stitch 稿）**：
  - 顶部头像按钮 → 砍（无账户系统）
  - 底部"家庭档案管理 + 偏好设置"两个入口 → 合并为一个"档案与设置"
  - Settings 独立页 M3 前不做；M3 起用半屏 sheet（极简），不做独立大页
- **v1.1+ 候选（不动）**：导出默认格式 / 共享管理 / 通知开关 / 显示语言偏好 / 关于与完整免责声明
