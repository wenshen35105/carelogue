## A. 核心产品能力（v1.1 头部候选）

- **跨 Apple ID 共享（CKShare）** —— 已在 M5 调研；与下面两条同族
- **照护者模式 / 家庭档案组（多成员切换）** —— design-review 搁置项；随跨 ID 共享一起
- **用药计划 + 服药提醒** —— M5 候选；本地通知
- **提醒（通知系统）** —— 复诊 / 记录提醒；与用药打包；v1 曾排除通知
- **导出 / 分享** —— 最小只读快照 → **已排 M5 · T38**；（后续）完整导出（格式选项）+ 共享管理

## B. AI 能力扩展

- **面诊录音 + 疑问翻译** —— 已转 M5 ✓
- **跨记录问答**（"铁蛋白这半年趋势怎么样"）—— spec 非目标；需多记录上下文
- **AI 体验打磨包** —— 术语过滤 / 语言一致性 / 长 PDF 提示（m3-bugs #6–8）
- （待议）视觉模型直读图像 —— 与"图像不离设备"原则冲突，如做需重评

## C. 孕期 / 模板增强（后置）

- **Journey 级元数据 chips**（预产期 / 血型 / OB）—— 等通用机制（自定义概要项或模板层）

## D. 平台扩展（远目标）

- **Android / Web** —— 远目标

- **E2E 加密中转（v2+）** —— 若 CKShare 路线不通的备选
- **自动导入医院数据 / 健康平台集成** —— 后期
- **找医生 / 医院信息** —— 数据源与成本问题，后置
- **中国区上架** —— M5 评估（备案 / 主体资质）
