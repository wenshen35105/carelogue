## A. 核心产品能力

- **照护者模式 / 家庭档案组（多成员切换）** —— design-review 搁置项；跨 ID 共享（1.0 已落地）之后的自然下一步
- （低优）**受邀方本地副本并进共享** —— 只影响共享上线前各自建过同一旅程的人；有用户反馈再做
- **导出 / 分享** —— 「发医生 / 备份」场景：最小只读快照与完整导出/导入均未做；1.2 候选

## B. AI 能力扩展

- **跨记录问答**（"铁蛋白这半年趋势怎么样"）—— spec 非目标；需多记录上下文
- **AI 体验打磨包** —— 术语过滤 / 语言一致性 / 长 PDF 提示（m3-bugs #6–8）
- （待议）**视觉模型直读图像** —— 与"图像不离设备"原则冲突，如做需重评

## C. 孕期 / 模板增强

- **孕周 tracker 内容层** —— 通用"目标日 + 进度环"已排 M8（T56）；按周内容（"柠檬大小"等）待 1.2
