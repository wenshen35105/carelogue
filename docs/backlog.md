## 内测后拍板（T29 反馈驱动）

- 随手记挂附件（M2 #7）
- 血压双值字段（M2 #8 → v1.1）
- **2026-09-30 自用反馈（6 条）**：
  1. **录音不能后台/离页** —— 录音时常要给医生翻 journey、看"想问医生的问题"；需支持录音中切页面（app 内浮层/迷你录音条）+ 后台录音（Background Modes: audio）
  2. **就诊 Log 只能记日期** —— 需支持具体时间（时:分）；⚠️ 可能涉及 schema / 展示格式，排期前先查现有字段是否已是 `Date`（仅 UI 截断则无需改模型）
  3. **测量 Log 不能加备注** —— 补备注字段（⚠️ 需确认模型是否已有 note 字段，否则属 schema 变更）
  4. **白话解释不应显示模型名** —— 当前露出 "Deepseek-v4.1-Flash"；用户侧去掉模型标识（如需保留可放调试/关于页）
  5. **就诊记录地点/医生无 type-ahead** —— 新建就诊时从历史记录里取已用过的地点、医生，支持联想输入 / 直接选取
  6. **面诊录音转写质量差** —— 实测一次，AI 回复"转写质量很差、大部分内容无法辨别"；需迭代：排查录音参数（采样率/格式/降噪）、转写引擎与语言设置（中英混说）、长录音分段，及失败时的用户提示
