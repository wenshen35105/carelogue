## Prompt

Create a single **1024×1024 px square** promotional image for "Carelogue Plus" (the subscription for the Carelogue app), in the exact same visual language as the existing Carelogue design in this project.

**Important**: this is one single square graphic asset (like an App Store promotional image) — NOT a phone UI mockup, NOT a screen design.

Composition & content:
- Warm off-white background (#F7F5F2), soft and airy, generous margins (keep the outer ~10% clear).
- Center: the Carelogue app icon mark (reuse the existing icon), gently presented — plus the wordmark "Carelogue" in a clean rounded sans-serif matching the app.
- Below the wordmark, a small caps label: "Carelogue Plus".
- One line of English copy beneath, modest size: "AI explanations for your health records".
- A soft, abstract hint of the explanation card (a plain rounded-rectangle silhouette / gentle apricot glow) as decoration — abstract only, no fake UI details.
- Apricot accent #D9784F used sparingly (a small detail, underline, or dot).

Hard constraints:
- No Apple device mockups, no device frames, no screenshots of the app.
- No prices, no discount or "free" text, no "App Store" wording or badges.
- Not glossy, not plastic, not stock-photo style. Calm, warm, human, quietly premium — matching the app.
- Must stay legible when displayed small: few large elements, strong contrast.

Output: one 1024×1024 PNG.
