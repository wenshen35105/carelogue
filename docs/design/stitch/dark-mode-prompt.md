# Carelogue · Stitch 深色模式 Prompt

> 用法：在 Stitch 的同一项目里发出，基于已有三屏出深色版；生成后导出 → 评审 → 数值定稿进 M2 的 T14 卡。

## Prompt（复制这段）

````text
Build DARK MODE versions of the three existing Carelogue screens (Journeys home /
Journey timeline / Report explanation). Keep the SAME layout, SAME components,
SAME copy, SAME typography and spacing as the light version — only the color
scheme changes.

Mood: calm and warm at night — a journal you open in bed, not a cold gray
console. Warm charcoal, never pure black, no neon.

DARK PALETTE:
- background: warm charcoal #17140F
- card surface: #221E1A
- primary text: warm white #F5F1EC
- secondary text: #A39C93
- accent (apricot, brightened for dark): #E08A63
- hairline / dividers: #332E28

Per screen:
1. Journeys home — same journey cards; "进行中" pill and accents in brightened
   apricot; "+ 新建 Journey" dashed card in a subtle dark stroke.
2. Journey timeline — same connector line and dots (accent dots in #E08A63);
   measurement collapse card; report card with the "已生成解释" highlight in a
   soft warm tint over the dark surface.
3. Report explanation — explanation card header on a subtle warm-tinted panel;
   term chips as outlined pills; questions list and disclaimer legible on dark.

Show all three dark screens side by side (for comparison with the light set).
````
