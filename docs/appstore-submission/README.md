# 1.0 提审材料包

| 文件 | 内容 |
|---|---|
| `metadata-fields.md` | **逐字段填写手册**（对照 ASC 版本页：Promotion Text / Description / Keywords / URL / 版权 / 审核信息 / 发布方式…） |
| `review-notes.md` | 审核备注（复制进 ASC Notes 字段） |
| `posters/` | **上传 ASC 的定稿截图**（海报套版，精确 1284×2778；`en-CA/` 传英文（主语言）listing，`zh-Hans/` 传简体中文 listing） |
| `screenshots/iphone-6.5/` | 海报的**底图来源**（模拟器直出 1284×2778，中英各 7 张；换底图后跑 `tools/appstore-posters/make-posters.py` 重出海报） |
| `reference/` | 老板导出的 ASC 版本页 PDF + 4 张转图（原始依据） |

流程：按 `metadata-fields.md` 的 §D checklist 逐项过 → 提审；发布方式=手动。
