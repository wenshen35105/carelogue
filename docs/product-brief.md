# Carelogue — Product Brief v0.2

> 命名定稿（2026-09-16）：**Carelogue**（发音 care-log）。术语表 v1 已定。精查备注：韩国有同名韩语养老照护产品（케어로그，市场不重叠）；carelogue.com / .app 被占；carelogue.ca / .health / .io / .care / .co / .me 可注册。

## 一句话

患者视角的就医旅程 app：把散落的预约、面诊、报告、医嘱聚合为一条看得懂的时间线，配一个可随时开关的 AI 助手。

## 目标用户（按优先级）

1. 加拿大华人家庭（新移民 / 双语家庭 / 准父母）——第一版从孕期 journey 自用开始
2. 更广的移民与多语言群体（v2：语言切换）
3. 任何被医疗文书和等待流程困住的患者

## 核心概念（术语表 v1）

- **Journey · 旅程**：一段健康目的的时间线容器（孕期、拔智齿、慢病）
- **Log · 记录**：旅程时间线上的一个块（伞词），内部分三种 kind：
  - **就诊 Encounter**：面诊 / 体检 / 抽血 / 影像（UI 按类型显示，不显示"Encounter"）
  - **随手记 Quick Log**：瞬时感受 / 症状 / 备注（即时生效，可被引用进摘要）
  - **测量 Measurement**：体重 / 血压等数值（图表视图，不堆主时间线）
- **Artifact · 文档**：报告 / 处方 / 转诊信，挂在对应就诊上
- **Profile · 档案**（全局层，跨 Journey）：过敏与不良反应 / 长期用药 / 疫苗记录 / 既往病史与手术史
- **Summary Card · 摘要卡**：给医生看的一页 = Profile 摘要 + Journey 摘要
- **Onboarding · 引导**：Wizard 式首启流程

## 产品原则

1. **Local-first**：数据默认只存设备（"no server to breach"）
2. **AI 是动词**：按动作显式开启（点"解释这份"才处理这一份）；旅程级可一键全关
3. **Server 不存数据**：AI 走无状态转发（处理完即忘，不落盘）；账务走订阅系统——订阅解锁 AI 服务
4. **不做 EHR、不做公开评价**：个人工具定位；"找医生"用官方数据（CPSO）+ 私人记录
5. **界面双语**：中英并排、中文优先；品牌名 Carelogue（英文，无中文名）

## 数据与同步（架构决策）

- **AI 处理（无状态转发）**：
  - 单文档解释 = 天然无状态（发一份 → 处理 → 返回 → 结果存客户端）
  - 跨记录问答 = **客户端组装上下文**（本地挑选相关记录随请求发出），服务端仅校验订阅 + 代理转发（流式），处理完即忘
  - 零保留配置：模型 API 走 zero-retention 条款；转发层无日志 body、不落盘、流式透传
  - 文案准则：不说"数据永不离开设备"，准确表述为"不存储；仅在你使用 AI 功能时短暂处理"
- **同步**：
  - 同一 iCloud 账号（夫妻等）：CloudKit 私有库自动跨设备同步（MVP 免费天然）
  - 不同账号（父母等）：MVP = "导出分享"（摘要/报告 → PDF 或加密包，经 iMessage/微信）；v1.1 = CloudKit 共享（CKShare，需对方 Apple 设备）
  - 跨平台（Android/Web）时的路线：E2E 加密中转（server 只见密文）——v2+，非 MVP
  - 权限模型（2026-09-25 定）：**按 Journey 选择性共享**（共享孕期，不共享全部）；参与者**可读写**——CloudKit 现状不支持只读角色（T39 实施中，见 `ck-share-study.md`）

## 功能集

**MVP（第一版，自用先行——太太的孕期 journey 先跑起来）：**

- 创建 Journey → 时间线视图
- 添加 Log（三种 kind）+ 上传照片 / PDF
- 报告"解释"：白话 + 中文 + 术语卡 + 该问医生的问题
- 手动录入；无账号、无同步

**v1.1 / v2（排队，不在 MVP）：**

- 就诊摘要卡导出
- 照护者共享（家人多角色）
- 面诊录音 → 转写 → 翻译 + 摘要（事后模式；实时翻译后置）
- 提醒（复查 / 用药）
- 数据同步（用户自己的 iCloud / 云盘）
- 找医生（CPSO 聚合 + 语言筛选）
- 多语言界面扩展

## 商业化

订阅制解锁 AI 服务（server 不存数据）。价格与细节验证期后再定。

## 合规边界

- 只做信息翻译 / 导航 / 记录，不做诊断或治疗建议——保持在 Health Canada SaMD 排除范围（信息类工具）内
- 处理患者数据前完成 PHIPA / PIPEDA 咨询；local-first 架构先行
- 内置医疗建议免责声明
